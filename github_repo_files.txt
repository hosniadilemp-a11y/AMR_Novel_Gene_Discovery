GitHub Repository File Audit for Paper 1
=========================================
Manuscript Title: Structure-guided prioritization of divergent virulence and resistance candidates in an open pangenome clinical Escherichia coli isolate
Isolate: Escherichia coli QA5221 (ST354)

To ensure absolute reproducibility of the analyses and findings presented in the manuscript, the following datasets, alignments, models, and biophysical trajectories must be archived in the GitHub repository (https://github.com/hosni-sassi/AMR_Novel_Gene_Discovery) or registered databases.

1. Genomic Sequences & Assembly Assets
---------------------------------------
* Raw Sequencing Reads (Illumina MiSeq 2x250 bp):
  - NCBI SRA: SRR39314025 (BioProject: PRJNA1481519)
  - Raw files: QA5221_S16_L001_R1_001.fastq.gz, QA5221_S16_L001_R2_001.fastq.gz
* De Novo Genome Assembly:
  - GenBank Accession: GCA_XXXXXX (to be updated on final publication)
  - FASTA file: QA5221_assembly.fasta (contains 60 contigs >= 500 bp)
* Annotation Output:
  - Prokka functional annotation GFF3: QA5221_annotation.gff
  - Prokka functional annotation GenBank format: QA5221_annotation.gbk

2. Pangenomic & Comparative Surveillance Datasets
--------------------------------------------------
* ST354 Clonal Complex Cohort (n = 32):
  - List of NCBI RefSeq accessions: reference_st354_genomes_list.txt (Table S2)
  - Panaroo presence/absence matrix: pangenome_matrix_st354.csv
  - Panaroo core genome alignment FASTA: core_alignment_st354.aln
* Expanded Global E. coli Cohort (n = 401):
  - List of RefSeq accessions: global_cohort_genomes_list.txt
  - Panaroo presence/absence matrix: pangenome_matrix_global.csv
* GWAS & Statistical Outputs:
  - GWAS association Fisher's test results: pan_gwas_association_results.csv (Table S11)
  - Codon bias and base composition statistics: descriptive_stats_partitions.csv (Table S6)
