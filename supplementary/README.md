# Supplementary Materials Curation Folder

This directory contains research tables and datasets supporting the manuscript's findings.

## TSV Data Tables

*   `Table_S1_Assembly_QC.tsv`: Draft genome assembly quality assessment parameters (N50, L50, GC, mosdepth read-mapping depth).
*   `Table_S2_ST354_Cohort_Accessions.tsv`: NCBI GenBank accessions for the clinical cohort genomes and outgroup reference genomes.
*   `Table_S6_Codon_Bias_Statistics.tsv`: Gene statistics (length, GC, GC3 codon bias) and Mann-Whitney U hypothesis testing comparisons across core, accessory, singleton, and acquired resistance gene partitions.
*   `Table_S8_Foldseek_Alignments.tsv`: Reconciliation inclusion matrix detailing length, Pfam domains screen, GC depression significance, and TM-score fit parameters for prioritized candidates.
*   `Table_S11_PanGWAS_Results.tsv`: Ranked significant orthologous gene hits associated with lineage pangenome-wide association studies (PanGWAS).

## Full Datasets

*   `pan_gwas_association_results.csv`: Comprehensive list of orthologous gene clusters analyzed by PanGWAS along with sensitivity, specificity, Odds Ratio, Fisher's exact test p-values, and FDR Q-values.
*   `Supplementary_Data_1_1200_Genomes_Catalog.tsv`: Machine-readable catalog of all 1,201 genomes (focal clinical isolate QA5221, 400 ST354 lineage genomes, and 800 species-wide stratified reference genomes) with NCBI accessions, phylogroup classifications, and direct FTP download links.
